# 简历工作台（本地版）

一个放在自己电脑里的简历编辑器：左边加减板块，纸上直接改字，主题、背景、贴图、分组排版和 arXiv 式左侧标记随手换，AI 负责出风格、画小贴图、润色文字。不用装数据库，不用登录任何网站。

效果图在 `screenshots/` 里（主界面、主题面板、AI 面板、打印效果）。

## 启动

需要先装 **Node.js 18 或更高版本**（<https://nodejs.org> 下 LTS 即可，装完重开终端）。不需要 `npm install`，没有第三方依赖。

- **macOS**：双击文件夹里的 `启动.command`
- **Windows**：双击 `启动.bat`
- **或者终端里**（任何系统）：

```bash
cd 到本文件夹
node server.mjs
```

启动后会自动打开浏览器，默认地址是 <http://127.0.0.1:7788>。如果 7788 被占用，会自动往后找端口，以终端里打印的地址为准。

停止：关掉终端窗口，或按 `Ctrl + C`。

## 通用模板

压缩包里附了 `模板-通用简历.json`，是一份**不含个人信息的占位模板**：打开应用 → 设置 → 导入备份 → 选它。

它包含：基本信息（姓名 / 大学 / 专业 / 预计毕业时间 / 电话 / 邮箱）、教育经历、实习经历、项目经历、专业技能、荣誉奖项、自我评价。导入后按自己的情况改就行。

应用默认打开的是虚构示例；压缩包里**不包含** `data/resume.json`，你在本机编辑的内容不会被带进压缩包。

## 怎么用

### 板块

- 左侧「＋ 添加板块」：基本信息、工作经历、项目经历、教育经历、个人简介、专业技能、证书荣誉，或自定义。
- 拖动板块行可以排序；眼睛图标隐藏/显示；↑ ↓ 微调顺序；垃圾桶删除。
- 每个板块的标题、每一条内容都能直接在纸上点开改。
- 鼠标移到板块标题上，右边会出现加条目、上移、下移、删除的小按钮；移向按钮时它们会多停留一会儿，方便点中。
- 条目里的描述：按 `Enter` 新增一条，空行按 `Backspace` 合并到上一条。

### 基本信息

「基本信息」是一个普通板块，没有单独的大字姓名行；每一行就是一个可增删的小模块：

- 点板块标题右边的 **＋** 加一行；每行右侧的按钮可以上移、下移、复制、删除；
- 每行内容完全自由，例如「姓名：李明」「大学：北京大学」「专业：计算机」「预计毕业时间：2027.06」「电话：…」「邮箱：…」；
- **单行样式**：鼠标移到这一行，点右侧的 **Aa**，可以单独改字体、字号、字重、颜色；点「跟随统一设置」恢复；
- **统一设置**在「主题 → 排版 → 基本信息」，改的是所有信息行的基准；点「统一应用到所有行」会用统一设置覆盖掉所有单行样式；
- 头像开关在「主题 → 头像」，打开后显示在基本信息右侧；
- 板块本身也能拖动、隐藏、删除。

### 条目的统一格式

每条经历统一成：标题 + 时间 / 副标题 · 城市 / 描述。

- 副标题和城市合并成了一行，鼠标移到这行上，点右侧的 × 就能删掉整行；
- 条目右侧的滑杆图标是「显示 / 隐藏字段」：标题、时间、说明都可以单独开关；隐藏后纸面不显示，内容仍保留；还可以勾「时间另起一行」，不让时间跟标题挤在一行；
- 描述默认带小圆点；点条目右侧的「列表」图标可以在「有圆点 / 无圆点」之间切换，想写段落时就不显示分点；
- 不想要某条，直接删整条，或把里面的文字清空。

### 左侧 arXiv 标记

A4 左右页边距 24mm，左页边距里有一条像 arXiv 论文左侧的竖排灰色编号，上下居中：

- 默认 1 列：`arXiv:XXXX.XXXXXv1 [cs.SE] 18 Oct 2026`，随便改成你自己的编号；
- 最多 3 列，从最左边开始向右依次排开；
- 两种改法：直接在纸上点那行竖排字改；或者在「主题 → 左侧标记」里编辑，还能调字号（9–18px）、增删列；
- 浅灰 + 衬线字体，打印时保留；不想要可以整体关掉。

### 模块小鲸鱼

每个板块标题前面有一只小鲸鱼 emoji，按板块从上到下的顺序奇偶交替：

- 第 1、3、5… 个板块是 🐳，第 2、4、6… 个是 🐋；
- 拖动排序、隐藏板块后会自动重新排列，始终保持交替；
- 「主题 → 模块小鲸鱼」里可以整体隐藏；
- 用的是系统 emoji 字体，导出 PDF 时会一起打印。

### 排版（字体 / 字号 / 颜色）

「主题 → 排版」分成三组，各改各的：

- **基本信息**：字体、字号（9–32px）、字重、颜色；单行样式在纸上点 **Aa** 单独设置；
- **正文主体**：字体、字号、颜色（条目标题、描述、技能、荣誉等）；
- **各节标题**：字体、字号、颜色，颜色可以选「跟随主色」。

基本信息分两级：统一设置 → 单行样式。单行样式优先；点「统一应用到所有行」会用统一设置覆盖所有单行样式，点单行弹层里的「跟随统一设置」可以撤销这一行的覆盖。

改完立即生效。下面的「行间密度」只影响间距，不会覆盖你设的字号。

### 自由度的边界

- 样子可以很自由，但内容不会被样式隐藏丢掉：条目字段关掉只是不显示，重新打开还在；
- 统一样式和单行样式分开，想统一就点「统一应用到所有行」，想保留个别行就只改那一行；
- 这样既不会出现「改了一个地方，整页都乱」，也不会被固定模板卡住。

### 主题与背景

顶部「主题」：

- 10 套背景预设（极简白、商务蓝、墨绿、暖纸、紫罗兰、石墨、藏青、朱砂、天青、素灰）
- 主色（可自定义取色）
- 板块标题样式：无装饰 / 下划线 / 竖线 / 色块
- 行间密度：标准 / 紧凑（只改间距）
- 头像上传与显示开关

### 贴图

顶部「贴图」：

- 12 个内置小图案，点一下加到纸上
- 上传自己的 PNG / JPG / SVG
- 加到纸上后：直接拖动位置；右下角圆点拖动缩放；上方圆点拖动旋转（接近 90° 会吸附）
- 选中后可用浮动工具条复制、删除，面板里还能调大小、旋转、透明度、颜色

### AI（背景风格 / 贴图 / 润色）

顶部「AI 助手」：

- **生成背景风格**：用一句话描述感觉，AI 返回配色 + 字体 + 标题样式 + 背景 CSS，先预览，「应用到简历」才生效。
- **生成小贴图**：描述图案，AI 生成一张 SVG，预览后「加到简历上」。
- **润色文字**：先在纸上点一段文字，再选「更专业 / 更精简 / 更量化」或写自定义要求，结果预览后「替换原文」。

AI 用的是本机 DeepSeek Harness 的登录态，不需要填 API Key：

- 服务端在每次请求时读取 `~/.dsh/.credentials.yaml` 里的登录 token，调用 DeepSeek 的 Anthropic 兼容接口，模型 `deepseek-flash`。
- 关掉了长思考，一般 2–5 秒出结果；内容比较长时 10 秒左右。
- 如果提示登录失效，打开 DeepSeek Harness 重新登录一次即可。
- 想换模型或改成自己的 DeepSeek API Key，可以用环境变量：

```bash
AI_MODEL=deepseek-chat node server.mjs
AI_API_KEY=sk-xxx node server.mjs      # 同一个 DeepSeek 的 key
```

### 导出

- **导出 PDF**：点右上角按钮（或 `⌘P`），在打印窗口里：
  - 目标选「另存为 PDF」
  - 边距选「无」
  - 勾选「背景图形」，背景和贴图才会打印出来
  - 取消「页眉和页脚」
- **备份 / 导入**：顶部「备份」导出 JSON；设置面板里可以导入备份。

## 迁移到其他电脑（macOS / Windows）

可以。整个文件夹就是全部，不写注册表、不装服务、没有依赖。

1. **拷走文件夹**：把 `简历修改器` 整个文件夹复制到新电脑（或解压压缩包）。
2. **装 Node.js**：新电脑装 Node.js 18+（<https://nodejs.org>，选 LTS）。
3. **启动**：
   - macOS 双击 `启动.command`
   - Windows 双击 `启动.bat`
4. **带走简历内容（可选）**：
   - 旧电脑顶部「备份」导出 JSON → 新电脑「设置 → 导入备份」
   - 或者直接把旧电脑的 `data/resume.json` 复制到新电脑同名位置
5. **AI 怎么办**：
   - 新电脑也装了 DeepSeek Harness 并登录了 → 直接可用，和这里完全一样（服务端读 `~/.dsh/.credentials.yaml`，Windows 下是 `%USERPROFILE%\.dsh\.credentials.yaml`）。
   - 新电脑没有 DSH → 用你自己的 DeepSeek API Key，还是同一个 DeepSeek：
     - macOS / Linux：`AI_API_KEY=sk-xxx node server.mjs`
     - Windows PowerShell：`$env:AI_API_KEY="sk-xxx"; node server.mjs`
     - Windows CMD：`set AI_API_KEY=sk-xxx && node server.mjs`

小提示：

- Windows 上没有苹方 / 宋体 SC 时会回退到微软雅黑 / 宋体，版式可能有细微差异，导出前看一眼预览。
- 文件夹放在中文路径下也没问题（脚本用 `%~dp0` 定位自己）。
- 换电脑后第一次打开会生成新的 `data/`，属于正常现象。

## 常见问题

**双击没反应 / 提示没有 Node.js**
先装 Node.js 18+（<https://nodejs.org>，或 macOS 用 `brew install node`）。macOS 的启动脚本会自动找 `/opt/homebrew/bin/node` 和 `/usr/local/bin/node`；Windows 需要 Node 在 PATH 里（安装时默认就会加）。

**Windows 上双击 `启动.bat` 一闪而过**
在本文件夹按住 Shift + 右键 →「在终端中打开」，运行 `node server.mjs`，就能看到具体报错。常见原因是 Node 还没装好，或装完没有重开终端 / 资源管理器。

**端口被占用**
会自动换成 7789、7790…，看终端里「打开：http://…」那一行。

**AI 检测失败：Load failed / Failed to fetch**
这通常不是 AI 本身的问题，而是页面没连上本地服务。看页面顶部是否出现黄色提示条：

- **「这个页面是直接打开的文件」**：你是双击了 `public/index.html`。关掉它，双击文件夹里的 `启动.command`（Windows 用 `启动.bat`），用自动打开的 http://127.0.0.1:7788 页面。
- **「本地服务未连接」**：终端窗口可能被关掉了。重新双击启动脚本，再点提示条右侧的「重新检测」。简历内容还在浏览器里，不会丢。

设置面板里的「AI 连接」也会给出同样的诊断，并带「重新检测」按钮。

**AI 很慢或报错**
先看设置面板里的「AI 连接 → 测试连接」。报登录失效就去 DeepSeek Harness 重新登录；报网络错误就检查代理。

**打印出来没有背景**
打印窗口 →「更多设置」→ 勾选「背景图形」。贴图和底色都依赖这个开关。

**页面内容超过一页**
A4 预览里会有一条蓝色分页参考线（右下角可开关）。超过一页时，打印会自然分页；简历建议控制在一页内，可以把「行间密度」调成紧凑或删减内容。
