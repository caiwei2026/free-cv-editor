# 简历修改器

一个在自己电脑上用的简历编辑器：打开就能改，改完导出 PDF。日常编辑和保存都在本机，不上传。

![主界面](screenshots/overview.png)

## 快速开始

第一次用需要装 [Node.js](https://nodejs.org) 18 或更高版本（选 LTS，安装时一路下一步）。

- **macOS**：双击文件夹里的 `启动.command`
- **Windows**：双击 `启动.bat`

浏览器会自动打开。没打开就手动访问 <http://127.0.0.1:7788>。

> 不要直接双击 `public/index.html`，那样保存和 AI 会不正常。启动后的终端窗口要留着，关掉它就停止服务了。

## 开始改

- 左侧「＋ 添加板块」加板块；拖动排序，眼睛图标隐藏，垃圾桶删除。
- 板块标题右边的小眼睛可以隐藏/显示标题；示例里的「基本信息」标题默认隐藏，让姓名和岗位先出来。
- 纸上的字都能直接点开改。
- 鼠标移到板块标题或某一条的右侧，会出现操作按钮：加一条、上移、下移、复制、删除。
- 顶部有撤销 / 重做；不在输入框里时，⌘Z / Ctrl+Z 也能用。
- 「基本信息」是普通板块，一行一个小模块（姓名、电话、邮箱……），点 ＋ 加一行，不需要的行删掉；姓名、求职方向、联系方式默认形成了大、中、小的层次。
- 每一条经历有标题、时间、说明和分点。不需要时间或说明，点它们旁边的 × 可以直接删掉；想恢复，点条目右侧的滑杆按钮重新打开。不想要分点，点列表按钮切换。
- 「核心能力」「个人简介」这种文字板块，鼠标移到段落右侧也能点 + 加分点；分点同样可以切换圆点。
- 文字板块的说明段可以单独隐藏：点条目右侧滑杆按钮，取消「段落」，只留分点，不会留占位空行。
- 描述里按 Enter 新增一条，空行按 Backspace 合并。

## 换外观

- 顶部「主题」：先排版（字体/字号/字重/颜色）、主色和行间密度，再是背景、标题样式、头像；
- 小鲸鱼、arXiv 左侧标记、DeepSeek 鲸鱼水印这些个性化内容收在「个性装饰 / 高级（开发者）」里，默认收起；水印默认右上角、50% 透明度，可调大小/透明度；
- 示例和模板默认关闭这些装饰；
- 顶部「贴图」：内置小图案或上传图片，拖动、缩放、旋转。

## 可选：AI 助手

顶部「AI 助手」把「润色文字」放在最前面：先在纸上点一段文字，再选改写方式。生成后会对照显示原文和改写后；点「替换原文」只替换生成时选中的那段，即使你中途点了别处也不会串。

也可以生成背景风格、小贴图。AI 需要本机先配置好，配置方法见开发者说明；没有配置不影响编辑和导出。替换后可以用顶部撤销恢复。

只有你主动使用 AI 时，输入或选中的内容才会发给 DeepSeek；不用 AI 时简历只在本机。

## 导出和备份

- 页面底部会显示「约 X 页」；右上角「导出 PDF」：打印窗口选「另存为 PDF」，边距选「无」，勾选「背景图形」。
- 板块可以跨页，但标题会跟着下一条内容；普通分点保持完整，特别长的经历允许合理跨页，不会因为整块避让空出大段。
- 顶部「备份」导出备份文件；「设置」里可以导入，换电脑用它；
- 如果本机 `data/resume.json` 被外部修改过，打开「设置 → 从本机文件重新载入」，会用文件覆盖页面上的浏览器缓存版本。
- 顶部保存状态：**已保存到本机** 才是文件写好了；**已存浏览器 · 文件待保存** 是还在写；**浏览器已存 · 文件未保存** 时点一下状态可以重试。

## 常见问题

**打不开 / 双击没反应**
先装 Node.js 18+，装完重开终端/资源管理器。macOS 首次被拦截时，右键 `启动.command` → 打开。不要直接开 `public/index.html`。

**页面提示未连接**
终端窗口可能被关了；重新双击启动脚本，再点页面上的「重新检测」。

**AI 用不了 / 检测失败**
先看「设置 → AI 连接」的检测提示；AI 需要本机先配置好，详见开发者说明。不用 AI 不影响编辑和导出。

**内容超过一页**
把「行间密度」调成紧凑，或删减内容；页面底部会显示约几页，右下角的分页线可以开关。

**保存状态显示「文件未保存」**
浏览器里已经存住了；点右上角那个状态重试，或检查本地服务是否还开着。

**Windows 双击一闪而过**
确认 Node.js 已安装好，然后在本文件夹打开终端运行 `node server.mjs` 看具体提示。

## 开发者 / 高级

下面这些是个性化或开发者功能，普通使用可以完全忽略：

- arXiv 式左侧标记、小鲸鱼
- 基本信息逐行字体/字号/字重/颜色、统一覆盖
- 条目字段的底层开关、时间另起一行
- AI 的 DSH token / API Key、目标锁定
- 撤销/重做历史、保存状态、分页规则
- DeepSeek 鲸鱼水印（图标来源 / 透明度 / 大小）
- 数据文件结构、Git 同步、打包

详见 [开发者说明.md](开发者说明.md)。
